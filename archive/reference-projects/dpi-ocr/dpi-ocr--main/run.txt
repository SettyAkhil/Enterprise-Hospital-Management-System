===============================================================================
                       KEPPLER OCR RUN & DEPLOYMENT GUIDE
===============================================================================

1. HOW TO START THE ENTIRE APPLICATION
--------------------------------------
Run the followi ng command from the project root directory:

    docker compose up -d --build

 This starts all necessary microservices:
  - Postgres Database (Port 5433)
  - Redis Server (Port 6379)
  - Qdrant Vector Store (Port 6333)
  - Celery Worker (OCR & Summarization background processing)
  - FastAPI Web & API Server (Port 7620)


2. HOW TO ACCESS THE WEB APPLICATION
-----------------------------------
Open your browser and navigate to:

    http://localhost:7620


3. HOW TO CHECK SYSTEM STATUS
-----------------------------
To view the status of all running containers:

    docker compose ps


4. HOW TO VIEW LOGS
-------------------
To check live logs across all services:

    docker compose logs -f

To view logs for specific services:
  - API Logs:    docker compose logs -f api
  - Worker Logs: docker compose logs -f worker


5. HOW TO RESTART THE APPLICATION
---------------------------------
To restart the services (e.g. after code modifications):

    docker compose restart

To restart specific containers:

    docker compose restart api worker


6. HOW TO STOP THE APPLICATION
------------------------------
To stop all services safely:

    docker compose down
